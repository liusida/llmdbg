# llmdbg

`llmdbg` is an early-stage debugger for stepping through language-model layers
and presenting human-readable interpretations of internal vectors. It is
designed to integrate with editors through the Debug Adapter Protocol (DAP).

The debugger is under active development. This initial release establishes the
package and command-line interface.

```console
pip install --pre llmdbg
llmdbg --version
```
